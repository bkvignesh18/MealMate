# MealMate 🍴 
MealMate is a Django-based food delivery and restaurant management application. 
It allows customers to sign up, browse restaurants, view menus, add items to their cart, and place orders. 
Restaurant owners can manage their restaurants and menus through a simple admin interface. 
--- 

## ✨ Features 
- **Authentication**
  - Customer sign-up and sign-in
  - Basic admin login

- **Restaurant Management**
  - Add new restaurants with name, cuisine, rating, and image
  - Update or delete existing restaurants
  - View all restaurants in the system - **Menu Management**
  - Add menu items (name, description, price, vegetarian flag, image)
  - Update restaurant menus
  - Prevent duplicate items
    
- **Cart & Orders**
  - Add items to a customer’s cart
  - View cart with total price calculation
  - Place orders and clear cart after checkout
--- 

## 🛠️ Tech Stack 
- **Backend**: Django (Python)
- **Frontend**: Django templates (HTML, CSS)
- **Database**: SQLite (default)
- **Admin Panel**: Django’s built-in admin site
